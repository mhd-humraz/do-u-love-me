## 💘 Do You Love Me? – Cute Love Interaction Page

A playful and animated webpage made with HTML, CSS, and JavaScript — designed just to impress that special someone. 💝


---

### ✨ Features

- 💬 A sweet question: *"Do you love me?"*
- 😆 Animated "No" button that keeps running away
- 💖 A "Yes" button that leads to a loving response
- 🎨 Beautiful styling with love-themed colors and animations

---

### 🛠️ Tech Stack

- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Button animation and interactivity

---

### 📁 Files

```
do-you-love-me/
├── index.html      # The main page
├── style.css       # Styles for the love page
├── script.js       # Button animation logic
└── preview.mp4     # (Optional) Demo video of interaction
```

---

### 🧠 Idea Behind the Project

Just a cute and fun little project made to make your **girlfriend smile** — because sometimes the best code is written with ❤️.

---

### 🖱️ How to Use

1. Open `index.html` in a browser.
2. Watch the "No" button try to escape.
3. Click "Yes" and enjoy the surprise.
